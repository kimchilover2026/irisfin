# Un pequeño rincón para vos

Página romántica de una sola pantalla que utiliza el video original como fondo a pantalla completa. Incluye una tarjeta delicada, flores y pétalos animados, y un diseño responsive.

## Publicar en GitHub Pages
1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html`, `fondo.mp4` y `README.md` a la raíz del repositorio.
3. Entrá a **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná `main` y `/(root)`, y guardá.
5. Cuando termine el despliegue, GitHub Pages mostrará la URL pública.

## Nota
El video debe conservar exactamente el nombre `fondo.mp4` y estar en la misma carpeta que `index.html`. La reproducción comienza silenciada porque los navegadores suelen bloquear autoplay con sonido; el video puede reproducirse en bucle como fondo.
